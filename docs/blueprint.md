# **App Name**: AbsenceAce

## Core Features:

- Employee Login: Employee Login using Clerk single sign on.
- View Leave Balance: View personal leave balances.
- Submit Leave Request: Request time off, selecting the desired dates and leave type. 
- Leave Overview: Display a summary of upcoming time off, showing request status.
- AI-Powered Leave Insights: Based on leave history and employee role, provide AI-powered tool suggestions about best timing and impact of proposed leave.
- Manage Employee Requests: Admins should be able to see all requests.
- Approve or Reject Requests: Admins approve or reject requests based on policy.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) for a professional yet modern feel.
- Background color: Light purple (#F3E5F5), very desaturated, complements primary and creates a calming effect.
- Accent color: Teal (#009688), contrasting accent for important actions.
- Body font: 'Inter', a sans-serif font for a clean and modern look, ensuring readability across devices.
- Headline font: 'Space Grotesk', sans-serif font which complements 'Inter'; creates techy, modern look.
- Use clean, outline-style icons to represent different leave types and actions, ensuring clarity and ease of use.
- A clear, tabular format for displaying leave requests, making it easy to scan and process information.
